## 🌐 WebTrack

### Privacy-First Web Usage Tracker

**PROBLEM**

Browser usage time does not always represent meaningful active usage, making it difficult to understand where time is actually spent.

**HOW I SOLVED IT**

Built an event-driven Chrome extension using service workers, browser activity events, state-based tracking, website classification, aggregation and local persistence.

```text
Browser Events
      ↓
Service Worker
      ↓
Tracking + Classification
      ↓
Aggregation
      ↓
Local Storage
      ↓
Dashboard
```

## 🧠 TalentGraph AI

### Hiring Intelligence & Candidate Discovery

**PROBLEM**

Recruiters evaluating large candidate pools need to consider skills, experience, location, availability and overall suitability rather than relying only on keyword search.

**HOW I SOLVED IT**

Built a candidate discovery system around a 100,000-candidate dataset with ingestion, semantic matching, multi-factor scoring, filtering and recruiter-facing visualization.

```text
100K Candidates
      ↓
Data Processing
      ↓
Semantic Matching
      ↓
Multi-Factor Ranking
      ↓
Recruiter Dashboard
```

## 🧩 DevExplain AI

### AI-Powered Developer Understanding

**PROBLEM**

Understanding unfamiliar code and repositories requires manually tracing logic, architecture, complexity and documentation.

**HOW I SOLVED IT**

Built three AI workflows around a shared LLM layer:

```text
Code
 ↓
Analysis

Repository
 ↓
Review

Code
 ↓
Technical Article
```

The system generates structured explanations covering approach, dry runs, complexity, edge cases, optimizations and improved code.
